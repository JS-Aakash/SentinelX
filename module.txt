Module – Maintenance, Workforce Management, IPFS & Blockchain
Objective

Develop a complete Maintenance Lifecycle Management module for SentinelX that transforms AI maintenance predictions into real maintenance workflows, manages employees with role-based access, stores maintenance evidence on IPFS, and records immutable maintenance history on the Ethereum Sepolia Testnet.

This module must integrate seamlessly with the existing SentinelX architecture and AI pipeline.

9.9 Backend-Signed Blockchain Transactions (IMPORTANT)

Do NOT require MetaMask for users, judges, or engineers.

The application must interact with the real Ethereum Sepolia blockchain without requiring any browser wallet or extension.

Required Architecture

Requirements

Maintain a dedicated server wallet.

Store its private key securely in environment variables.

Use ethers.js v6 on the backend to sign blockchain transactions.

Only backend services communicate with the blockchain.

Users never expose private keys.

No browser wallet connection is required.

Benefits

Judges should simply open the hosted website.

No MetaMask installation.

No wallet connection.

No browser extensions.

No Sepolia configuration.

Yet all blockchain records must be real and publicly verifiable on Ethereum Sepolia.

Important Requirements
Do not modify any existing AI, machine learning, dashboard, or sensor modules unless necessary for integration.
Reuse the existing authentication and machine management systems wherever possible.
Ensure blockchain integration is production-like, with real Sepolia transactions but no MetaMask dependency for end users.
The hosted application should allow judges to browse, verify blockchain records, and inspect IPFS documents using only a standard web browser. Only authorized backend services should create blockchain transactions. This provides a smooth demonstration while preserving the authenticity of blockchain integration.
