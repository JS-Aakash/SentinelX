

The current implementation assumes every machine has exactly six sensors (Temperature, Vibration, Current, Voltage, RPM, and Sound). This is unrealistic because industrial machines have different sensor configurations. Refactor the entire application to support **dynamic sensor configurations** while preserving the current six sensors as the default template.

## Objective

Make SentinelX sensor-agnostic.

Every machine should define its own sensors during registration, and every module (dashboard, AI, IoT, simulation, analytics, prediction, etc.) must automatically adapt to that configuration.

---

# 1. Default Configuration

When registering a new machine, pre-populate these sensors:

* Temperature ×1
* Vibration ×1
* Current ×1
* Voltage ×1
* RPM ×1
* Sound ×1

The user can leave these unchanged or edit them.
